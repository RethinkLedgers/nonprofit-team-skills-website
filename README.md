# Nonprofit Team Skills Website

Marketing site for the [Nonprofit Team Skills](https://github.com/msg2ai/nonprofit-team-skills) project — 8 free Claude Code skills for non-profit teams.

Built with Next.js 16, TypeScript, and Tailwind-free custom CSS. Static export deployed to Vercel.

## Development

```bash
npm install
npm run dev
```

## Deploy

Pushes to `main` auto-deploy to Vercel.
